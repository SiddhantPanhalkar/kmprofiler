# Code of Conduct

Hey there! Thanks for checking out `kmprofiler` and wanting to get involved.

Since this is a small, solo-maintained open-source project, I don't think we need a massive 10-page
legal document. I just ask that everyone follows a few simple, common-sense rules:

1. **Be nice.** Whether you're opening an issue, submitting a pull request, or just asking a
   question, treat others with respect.
2. **Be constructive.** If you find a bug or think something in the code is poorly written, that's
   totally fine! Just explain the issue clearly and kindly. No need for aggressive or toxic
   language.
3. **Help each other out.** If you see someone asking a question in the issues that you know the
   answer to, feel free to chime in and help them.

If anyone acts out of line, becomes hostile, or harasses others, I will simply block them from the
repository.

Let's keep this space friendly, build cool tools, and make Kotlin Multiplatform development better
for everyone!
